# Лабораторная работа №3

## Цель
Изучить событийно-ориентированное программирование на Python с использованием библиотеки `pygame`.

## Реализовано
- Игра **Tetris**.
- Реализовано **7 типов фигур** (`I, O, T, S, Z, J, L`).
- Главное меню:
  - `Начать игру`
  - `Таблица рекордов`
  - `Справка`
  - `Выход`
- Экран `Справка` с правилами и управлением.
- Фоновая музыка и звуковые эффекты.
- Минималистичный интерфейс без лишних визуальных эффектов.
- Анимации:
  - анимация очистки линий (flash)
  - анимация завершения игры
- Таблица рекордов в JSON.
- Если результат **выше первой строки** таблицы рекордов, появляется диалог поздравления и ввод имени.

## Событийно-ориентированная модель
Приложение построено на цикле `pygame`:
- получение событий через `pygame.event.get()`
- обработка событий по состояниям (`menu`, `playing`, `highscores`, `help`, `new_record`)
- обновление модели игры по таймеру кадра
- перерисовка интерфейса

## Конфигурации и данные
Все настройки вынесены во внешние файлы:
- `config/game_config.json` — размеры окна, тайминги, очки, цвета, аудио, лимит рекордов
- `config/pieces.json` — описание геометрических фигур
- `config/texts.json` — пункты меню, тексты справки, подписи UI
- `data/highscores.json` — таблица рекордов

## Структура проекта
- `main.py` — точка входа и state-machine интерфейса
- `src/tetris.py` — игровая логика и отрисовка поля
- `src/audio.py` — загрузка и воспроизведение звуков/музыки
- `src/highscores.py` — загрузка/сохранение рекордов
- `src/config.py` — пути и загрузка конфигураций

## Запуск
```bash
python main.py
```

## Управление
- `← / →` — движение
- `↑` — поворот
- `↓` — ускоренное падение
- `Space` — мгновенный сброс вниз
- `P` — пауза
- `Esc` — выход в меню
